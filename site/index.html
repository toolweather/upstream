⟰ Upstream

Is the API your agent depends on up right now, and what's about to change?

Upstream checks ~40 AI and developer APIs every few minutes and watches the deprecation, model-retirement and pricing pages of the major LLM providers. One call tells your agent whether OpenAI, Anthropic, GitHub or Stripe will likely work right now, and whether the model it uses is being retired.

Honest notes

We read official public status pages and docs. A few providers have no machine-readable status page, so for those we check that the API answers. Model dates come from the provider's own page and every answer includes the excerpt we read, so you can double-check it. "unknown" means our check failed, not that the provider is down. No ads. A field called sponsored is reserved in responses and is always empty for now.
